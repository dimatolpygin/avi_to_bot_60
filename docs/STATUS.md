- **2026-07-23 — Этап 5: Словари и нормализация** — tag `stage-5-done` (`d4591a6`).

  **Решения, за которыми стоят данные, а не вкус**:
  (1) **ключ сводного словаря равен `products.family`** из ETL — разъедутся, и резолв
  запроса не свяжется с каталогом (тест сверяет множества ключей и семейств каталога);
  (2) **сорт канонизируется в тексте запроса ДО стемминга**: «вагонка сорт б» превращается
  в «вагонка сорт в», иначе лишний стем «б» остался бы у одного из двух запросов и на

  на этом, а не на равенстве полей;
  (3) **фаззи считается по словам, а не по стемам**: у «вогонка»/«вагонка» сходство 0.857,
  у стемов «вогонк»/«вагонк» — 0.833, то есть стемминг убивает ровно тот сигнал, ради
  которого канал заведён (закреплено отдельным тестом);
  (4) **гейт чужого домена не трогает банное, которого нет в прайсе** — «штиль», «веник»,
  «шайка», «ковш» отвечают «нет в наличии», а не «мы этим не занимаемся»; в гейт попадает
  только не наш профиль (техника, инструмент, еда, косметика, общестроительная отделка);
  (5) **длина разбирается только у мерных семейств** (вагонка, полок, наличник, брус, рейка):

  2000 мм, а не длина 2.0 м;
  (6) **побеждает самое конкретное совпадение**: у «камни для печи» одинаково подходят
  ключ «печь» и синоним камня «камни для печи» — приоритет по длине совпавшего варианта,
  иначе запрос про камни уходит в печи.

## Протокол обновления

**При старте сессии**: прочитать этот файл → `git tag -l "stage-*"` (сверить с таблицей) →
`git log --oneline -10` → открыть `07_ROADMAP.md` на текущем этапе → только потом работать.

**При взятии этапа**: обновить «Текущий этап» + «Активная работа», статус 🚧,
коммит `chore(status): start stage N`.

**При закрытии**: все чекбоксы `[x]` и проверены человеком → `git tag stage-N-done` →
в таблице ✅ + тег + коммит (`git rev-parse --short HEAD`) + дата → запись в «Историю закрытий» →
коммит `chore(status): close stage N`.

**Если заблокирован**: статус ⏸ + в «Известные блокеры» что ждём и что нужно для разблокировки.
