## Протокол обновления

**При старте сессии**: прочитать этот файл → `git tag -l "stage-*"` (сверить с таблицей) →
`git log --oneline -10` → открыть `07_ROADMAP.md` на текущем этапе → только потом работать.

**При взятии этапа**: обновить «Текущий этап» + «Активная работа», статус 🚧,
коммит `chore(status): start stage N`.

**При закрытии**: все чекбоксы `[x]` и проверены человеком → `git tag stage-N-done` →
в таблице ✅ + тег + коммит (`git rev-parse --short HEAD`) + дата → запись в «Историю закрытий» →
коммит `chore(status): close stage N`.

**Если заблокирован**: статус ⏸ + в «Известные блокеры» что ждём и что нужно для разблокировки.
