## Активная работа

**Этап**: 3 — Схема БД + Alembic. Не начат.
**Ветка**: `dev`
**Сводка задач**: SQLAlchemy 2.0 модели прайса, промптов, диалогов и лидов; Alembic
с `version_table_schema='sbavito'` и `include_schemas=True`; enum `account_kind` /
`availability` / `price_unit`; GIN trigram по `products.name` и `product_aliases.alias`;
сиды на 3 аккаунта; `alembic upgrade head` в entrypoint контейнера до старта бота.
**Как верифицируем**: `alembic upgrade head` на чистой схеме поднимает всё без ошибок,
`downgrade -1` откатывает, повторный сид не плодит дубли, `availability` по умолчанию `unknown`.
**Окружение**: `postgres16` (:5432) и `redis` (:6379) подняты, БД `sbavito` есть, схемы `sbavito`
в ней ещё нет; аннулированные таблицы Drizzle лежат в `public` — удалить на этом этапе.

## Протокол обновления

**При старте сессии**: прочитать этот файл → `git tag -l "stage-*"` (сверить с таблицей) →
`git log --oneline -10` → открыть `07_ROADMAP.md` на текущем этапе → только потом работать.

**При взятии этапа**: обновить «Текущий этап» + «Активная работа», статус 🚧,
коммит `chore(status): start stage N`.

**При закрытии**: все чекбоксы `[x]` и проверены человеком → `git tag stage-N-done` →
в таблице ✅ + тег + коммит (`git rev-parse --short HEAD`) + дата → запись в «Историю закрытий» →
коммит `chore(status): close stage N`.

**Если заблокирован**: статус ⏸ + в «Известные блокеры» что ждём и что нужно для разблокировки.
