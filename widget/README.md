# Виджет amoCRM «SBAvito — переписки ботов» (этап 14.7, кирпич 3)

Показывает менеджеру полную ленту диалогов ИИ-ботов (клиент + бот) из бэкенда
SBAvito. Родная лента amoCRM показывает только сообщения клиента (реплики бота в
кастомный канал amojo как исходящие не выходят — тупик 14.3b), поэтому переписку
целиком отдаёт этот виджет через `/api` (кирпич 2).

## Состав пакета
```
manifest.json     — метаданные, левое меню, поля настроек (адрес API + токен)
script.js         — логика: список чатов → переписка (fetch к /api)
i18n/ru.json      — тексты (ru)
i18n/en.json      — тексты (en)
images/logo.png   — ЛОГОТИП (нужно добавить, см. ниже)
```

⚠️ **Логотип не в git.** amoCRM требует `images/logo.png` (обычно 84×84 и
папку с иконками). Возьмите из `доступы/logo.svg` → экспортируйте в PNG нужного
размера и положите в `widget/images/`. SVG amoCRM для логотипа не принимает.

## Сборка и загрузка
1. Убедиться, что бэкенд отдаёт API: на сервере задан `PANEL_API_TOKEN`, nginx
   проксирует `/api` (см. `docs/DEPLOY.md`), `PANEL_CORS_ORIGIN` = домен вашего
   amoCRM (например `https://sbcompany.amocrm.ru`).
2. Положить `images/logo.png`.
3. Собрать zip **из содержимого** папки (manifest.json в корне архива, не в
   подпапке):
   ```bash
   cd widget && zip -r ../sbavito-widget.zip . -x '*.DS_Store'
   ```
4. amoCRM → Настройки → Интеграции → «Создать интеграцию» → внешняя, загрузить zip
   как приватный виджет. Установить, открыть настройки виджета:
   - **Адрес API**: `https://bot-admin.online`
   - **Токен доступа**: значение `PANEL_API_TOKEN` с сервера.
5. Пункт **SBAvito** появится в левом меню — открыть, проверить список чатов и
   переход в переписку.

## Проверка API до виджета
```bash
curl https://bot-admin.online/api/health
curl -H "Authorization: Bearer <PANEL_API_TOKEN>" https://bot-admin.online/api/chats
```

## Статус
Скелет готов и репо-агностичен; **живой smoke-тест — на реальном аккаунте amoCRM**
(у заказчика есть права на загрузку приватного виджета). amoCRM-специфика (точные
имена callback'ов левого меню, размеры логотипа) может потребовать правки по факту
первого запуска — это ожидаемо для виджета, собранного без доступа к аккаунту.
